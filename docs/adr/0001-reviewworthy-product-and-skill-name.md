# Separate the Reviewworthy product name from the descriptive Skill name

We use **Reviewworthy** as the project and repository brand, while the primary Skill is named **maintainer-first-contribution**. This keeps the public product name short enough to grow into a CLI, Action, and policy ecosystem while keeping the Skill invocation self-descriptive.

## Considered Options

- Use `maintainer-first-contribution` for both the project and Skill.
- Use `Reviewworthy` for the project and `maintainer-first-contribution` for the Skill.

## Consequences

The README, package metadata, and future CLI use `Reviewworthy`; workflow documentation and Skill metadata use `maintainer-first-contribution`.
