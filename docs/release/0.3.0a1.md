# Reviewworthy 0.3.0a1 release evidence

This alpha is a deliberate compatibility break. Packet, Signal, verification receipt, operation state, and remote marker `0.3` do not read, recognize, migrate, or reconcile older formats.

Release checks:

1. `PYTHONPATH=src python -m unittest discover -s tests -v`
2. `PYTHONPATH=src python -m reviewworthy eval run --json`
3. `python -m compileall -q src tests`
4. validate every JSON Schema and generated artifact fixture;
5. `python -m pip wheel --no-deps --no-build-isolation --wheel-dir dist .`;
6. install the built wheel in a clean environment and run `reviewworthy --version`;
7. inspect the staged diff and confirm all versioned public examples use only `0.3` contracts.

Provider-free tests cover private Packet/public Summary separation, base-tree policy authority, canonical subject identity, plan-bound receipts, Discussion GraphQL normalization, operation reconciliation, status/next output, command bounds, atomic writes, and malformed input totality. Live GitHub mutation is not part of the release test suite and requires a separately authorized canary.

The checklist above remains a release requirement; this support-document update
does not assert a new release, published tag, wheel validation, or live-provider
success. Checks newly executed for the recovery/workflow work are recorded
separately in [the session queue](../plans/recovery-and-workflow-queue.md) and its
selected session records.

Delivery uses a standard-library-only runtime on Python >=3.11, with CI configured
for Python 3.11, 3.12, and 3.13. The composite Action checks Python/Git prerequisites
and needs only read access to repository contents for checkout, full local Git
history, and runner event data. Consumers must use audited, published full commit
pins and avoid running untrusted head code with privileged events; see
[Action and CI guidance](../../references/action-and-ci.md).

The provider adapter supports public `github.com` repositories. Private security
reports follow the [maintainer-coordinated intake](../../SECURITY.md), outside the
CLI's public-reference contract. Saved current operations can be reconciled; an
uncertain pending create permits one explicitly confirmed `--retry-uncertain`
attempt only after manual inspection and a fresh complete zero-marker search.
Known objects and note failures require reconciliation. Delayed visibility and
concurrent writes leave residual duplicate risk; bounded inspection does not
provide global exactly-once delivery. See [remote recovery](../../references/remote-writes.md).
