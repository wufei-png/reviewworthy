# Security

Do not open a public Issue for a suspected vulnerability or include secrets in a public contribution. Submit reports through the repository's [private GitHub Security Advisory form](https://github.com/wufei-png/reviewworthy/security/advisories/new) with reproduction details, affected versions, and a suggested contact channel.

Security fixes still require a bounded Contribution Contract and verification record, but the private report is the contribution basis. Do not disclose an exploit publicly until the maintainers coordinate a safe release.
